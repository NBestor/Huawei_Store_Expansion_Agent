# 评审测试用例清单

对照赛题手册第 9 页"统一测试任务"与扣分红线整理，用于上线前自测与录屏演示。

## 一、基础生成

- 输入：指定产品 + 人群 + 场景 + 平台。
- 检查：检索是否成功、图文是否完整、产品事实是否都有依据。

## 二、换场景

- 同一产品，换人群/场景（如 大学新生开学 → 商务出差）。
- 检查：切入点、卖点顺序、图片方案是否发生实质变化。

## 三、换平台

- 同一任务，换平台（小红书 / 公众号 / 门店朋友圈）。
- 检查：结构、语气、图片数量、CTA 是否随平台改变（只改篇幅不算）。

## 四、干扰与修改

- 易混淆型号：给相近型号，检查是否串参数、是否提示区分。
- 不完整信息：只给"想买轻薄本"，检查是否追问/提示补充而非瞎编。
- 加价格/补贴/销量/评价：检查是否拒绝或标警告，不虚构。
- 临时修改：换渠道/删卖点/改人群，检查是否重新生成。

## 五、扣分红线（不能踩）

- 图片非 ima 或与型号不符 → 图片引用 0 分。
- 虚构价格/补贴/销量/奖项/用户评价 → 准确性与合规 0 分。
- 抄袭 / 伪造运行记录 / 隐藏人工代写 → 取消资格。

## 六、自测建议顺序

1. 基础生成（先跑通）。
2. 换平台（最容易看出差异）。
3. 换场景（验切入点变化）。
4. 干扰与修改（追问/拒答/重新生成）。
