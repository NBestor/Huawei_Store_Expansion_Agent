## 历史存档与修改功能（讨论定稿，待实现）

### 一、定位

把每次生成任务存成「可恢复的会话存档」，支持：查看历史、打开继续改、生成新版本、版本回退、删除。

### 二、已定案（2026-10-18 用户确认）

1. **修改保存方式**：生成新版本，不覆盖旧版本（配合版本回退）。
2. **恢复范围**：打开历史时，连同来源依据（facts / 引用 / 核验依据）一起恢复。
3. **允许删除**：提供删除单条、清空历史的入口。

### 三、存什么（全量）

- 任务设置：产品 / 人群 / 场景 / 平台 / 来源（本地 | ima | vmall）/ 引擎 / 补充要求。
- 最终结果：标题 / 正文 / CTA / 标签 / 图片（含来源）/ 引用 / 核验报告（✅⚠️❌）。
- 上下文依据：facts + 来源路径 + 选中卖点（points）+ 版本快照。
- 元数据：时间戳 / 版本号 / 导出状态。

### 四、存哪里 / 格式

- 位置：`app/.runtime/history.json`（或每个会话一个 JSON）。
- 格式：JSON；单条约几 KB，几十条也就几百 KB，不需要数据库。
- 安全：不含任何密钥；历史文件加入 `.gitignore`。

### 五、交互流程

1. 历史列表（标题 + 产品 + 场景 + 平台 + 时间 + 状态）。
2. 点「打开继续编辑」→ 恢复完整状态（草稿 + 引用 + 核验 + 卖点 + 依据）。
3. 继续改 → 保存 → 生成新版本（旧版本保留，可回退）。
4. 可删除单条 / 清空历史。

### 六、版本与回退

- 每个会话内部维护版本数组；每次保存 append 一个新版本。
- 「回退」= 切到历史版本快照。
