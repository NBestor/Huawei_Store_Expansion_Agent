# 统一输出格式（四段式）对齐方案

## 背景

赛题手册第 5 页要求输出固定四段式。本文档说明如何把现有返回结构对齐到四段式，供前端排版与导出使用。

## 四段式对应关系

| 手册要求 | 现有字段 | 说明 |
|---|---|---|
| 一、场景判断 | `strategy`（audience/scene/platform/angle/goal） | 目标人群/使用场景 + 用户问题/内容目标/平台 |
| 二、知识库依据 | `evidence`（facts/path/sources）+ `citations` | 产品型号/事实点/资料标题 + 逐字引用 |
| 三、图文软文 | `title`/`body`/`cta`/`tags` + `images` | 标题/正文/行动引导 + 图片名称/来源/位置/说明 |
| 四、核验结果 | `checks` + `audit`（blocking/suggestions） | 产品事实/图片型号/合规/待确认信息 |

## 待实现（等 Codex 改完代码后）

1. 前端预览区按四段式排版（场景判断 → 依据 → 软文 → 核验）。
2. 导出文本按四段式生成，字段完整。
3. 核验结果里显式加"图片型号核验"一项（对应手册"四、核验结果"的"图片型号"）。
