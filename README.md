# 华为 PC 图文营销工作台

支持本地 P1 事实、可选 ima 补充资料、自动发现并读取华为商城商品页、DeepSeek 生成与逐条事实核验、局部编辑、片段锁定、SQLite 历史版本和含实际配图的 PDF 图文方案导出。保留规则草稿供离线验证。

在线演示（阿里云 ECS）：http://47.97.59.219/

## 启动

侧栏提供首页、创作、作品、审核、历史入口。作品页专注正文与配图，编辑器默认收起；审核页显示当前作品的核验状态、待确认表述和依据摘录。点击待确认表述可回到作品页并选中原文，切换页面保留当前会话。

Windows 用户可直接双击根目录的 `启动工作台.cmd`。启动器会优先查找系统 Node.js，再查找 Codex 自带运行时，无须额外安装 npm 或依赖。它会在后台启动服务并打开默认浏览器；重复点击会复用 `0.3.0` 服务。若 3000 被旧版或其他程序占用，会依次尝试 3001–3009 并打开实际地址。启动失败时显示错误，日志位于 `app/.runtime/`。仅在没有任何可用 Node.js 24+ 时才需要安装 Node.js LTS。

需要 Node.js 24 或更新版本（使用内置 SQLite），无须安装第三方依赖。在项目根目录执行：

```powershell
node app/server.mjs
```

浏览器打开 http://127.0.0.1:3000 。服务仅监听本机。可通过 `PORT` 环境变量调整端口。

注意：本地网址需要服务正在运行才能打开；不能直接双击 `app/public/index.html` 代替启动服务。

测试：`node --test app/test/*.test.mjs`。受限环境可使用 Node.js 24 的 `node --test --test-isolation=none app/test/*.test.mjs` 在进程内运行。

## API 配置与验证

根目录 `.env` 会自动加载，已有系统环境变量优先。修改配置后重启服务。配置模板见 `.env.example`；密钥只在后端使用，不返回浏览器。

DeepSeek 使用 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`（官方地址）、`DEEPSEEK_MODEL`。测试阶段默认使用 `deepseek-flash`；需要切换时修改 `.env` 并重启服务。

ima 下载官方 Skill 后配置：

- `IMA_SKILL_SCRIPT`：官方 `ima_api.cjs` 的绝对路径。
- `IMA_OPENAPI_CLIENTID`：当前账号的 Client ID。
- `IMA_OPENAPI_APIKEY`：当前账号的 API Key。
- `IMA_KB_NAME`：可选，默认“任德耀新建华为PC知识库”。

`app/lib/ima.mjs` 调用官方脚本导出的 `imaApi`，保留每日更新检查，缓存写在 `app/.runtime/`。已实现找库、搜索、分页目录回退、Markdown/TXT/笔记原文和图片代理。支持实测的 `kb_id/kb_name` 和目录类型 99；优先按具体型号目录读取产品事实、限制和 images，避免混入价格卡及传播案例。ima OpenAPI 是赛事核心接入能力，但每日资料访问次数有限；日常开发和回归测试推荐本地资料，只有选择 ima 模式才会实际调用。凭证从 ima 客户端“Claw 配置”获取，并通过服务端环境变量 `IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY`、`IMA_KB_NAME` 配置。

打开工作台后点击“验证 ima 与 DeepSeek 连接”；这会检查凭证、模型可用性、目标库可见性。选择 ima 并完成一次生成，才验证完整资料链路。检索失败不会偷偷改用本地资料。

统一流程：P1 目录工具检索 → 带原文引用的场景草稿 → 独立逐条事实核验 → 有明确冲突时修订一次并复核 → 进入同一会话继续编辑。直接编辑停止 1.8 秒后自动保存为新版本并重新核验；划选文字可锁定或只让 AI 修改选中片段，选区外由程序保持原文。警告表示没有明确依据，允许用户决定导出；明确冲突、核验失败、图片不足或未保存内容禁止导出。

每次生成都会写入 `app/.runtime/studio.sqlite`。历史列表可以恢复草稿、任务设置、图片、引用、事实依据和核验报告；每次修改追加版本而不覆盖旧版，可在版本栏切换，支持删除单个会话或确认后清空。数据库和运行日志均已被 `.gitignore` 忽略，不包含 API 密钥。无需安装或启动独立数据库服务。

生成时默认自动优先选用官网产品图片：缓存命中则直接复用，否则从精确型号对应的华为官网产品页采集并缓存，也可提前浏览和手动勾选。自动选图按人群与场景挑选主视觉、外观及使用场景，过滤模糊占位图、获奖标识、部分功能示意图和重复尺寸。资源目录按型号图片索引核对，支持产品页面地址与资源目录名称不同的情况。作品会显示官网图片数量、已有素材数量及回退原因；官网不可用或数量不足时才补充已有素材。图片按型号存入 SQLite 独立缓存表，保留原图地址、来源页和采集时间，跨作品、重启、删除历史后可复用，并支持 PDF 实际嵌入。当前选图使用文件名与来源规则，不包含运行时的 AI 视觉内容审核。

文案作者固定为华为门店销售或品牌运营工作人员，成稿面向潜在顾客，介绍电脑亮点与应用价值并邀请咨询、到店体验。正文编辑目标为朋友圈180–320字、小红书650–900字、公众号1400–2000字（去空白统计，不含标题、CTA、标签；不是平台规定）。按平台输出不同段落结构；不足时尝试补足具体场景、推荐理由和过渡，初稿和事实修订稿均检查篇幅。篇幅提示不会替代事实准确，也不阻断因证据不足而停笔。卖点规划、成稿和局部改写共用销售身份；发现选购教程或内部指令泄漏时会自动改写。事实核验仍保留，不能为了宣传新增未经证实的价格、续航、兼容性或体验保证。公开案例与本轮抽样见 `Agent协同与任务梳理/平台宣传文案长度与结构研究.md`。

本地 P1 始终作为事实来源。选择 ima 时，它只作为补充来源，不替代本地资料。模型任务默认会从赛事提供的官方价格快照 CSV 中按精确产品名查找当前型号的华为商城商品页，并尝试自动读取 `item.vmall.com` 页面；也可手动补充 `www`、`item` 或 `m.vmall.com` 链接。网页只作为网页来源证据，不会伪装成文档或 ima 支持；不搜索其他网站，也不让模型自行裸搜。无法读取或型号不匹配会留在检索轨迹中，商城来源不会被用于替代文档/ima核验。

图文方案导出为 PDF：包含标题、发布文案、实际嵌入的配图、配图说明、来源、任务参数和检索接入说明。核验完整快照继续保存在 SQLite 历史中；审核区只呈现明确冲突和仅由商城网页支持的核验通过项，警告及由本地文档/ima 支持的通过项不进入人工关注清单。

DeepSeek 请求显式使用 `thinking.type=disabled`，避免默认高强度推理耗尽正文输出预算；生成与审核仍为独立请求，输出额度16384 token，截断结果不采用；若单次输出达到上限，会自动要求去掉冗余并返回完整JSON，保留正文目标篇幅和必要证据，最多重试一次。ima 返回220021表示当日资料获取额度用尽，可次日重试，或手动选本地参考验证；不会自动冒充ima来源。

## 当前边界

- 当前具体型号列表与 ima 目录映射来自赛事方本地目录；共享库改名、改目录时可能需要适配。
- ima 原文暂支持 Markdown、TXT、可访问笔记；PDF、Word、网页等尚未做内容解析。媒体仅支持指定腾讯 HTTPS 域名，重定向不自动跟随。
- 资料只用于证据约束，未重新访问每个官方产品页验证时效或图片授权。
- 独立审核是同一模型的另一请求，不等于人工审核或外部事实认证；图片按型号目录/索引选择，尚未做视觉核验。
- 会话和版本会持久化，但不是自由对话聊天记录；补充要求属于生成任务设置，后续片段修改通过编辑工作区完成。
- 不修改原始知识库；不要将密钥写入代码、文档或提交材料。
