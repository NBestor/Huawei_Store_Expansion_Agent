# 华为 PC 官方产品照片集

共 271 张图片，覆盖 10 个型号。打开 index.html 可离线浏览，并按型号、画面类型、关键词筛选。

- 照片索引.csv：适用于 Excel 的可筛选索引。
- 照片索引.json：结构化索引，可供工具读取。
- 型号子目录：华为消费者业务官网原图。
- 每条记录分列保存人工目视描述和官网图片索引标注。
- 浅色遮罩、空白屏幕、纯壁纸和其他背景动画素材已从照片集移除；结构拆件、证书和配件图保留作核对记录，但不会参与自动配图。屏幕、协同演示只可作画面说明，不能单独证明参数、功能范围、兼容性或随机配件；事实需回到官网正文核验。
- 细小界面文字未做 OCR 确认；人工画面描述仅覆盖整体场景。
- 来源为华为消费者业务官网的精确型号产品页及该型号图片索引。图片仅供内部选图核对，发布和授权请遵守官网与品牌素材规范。
